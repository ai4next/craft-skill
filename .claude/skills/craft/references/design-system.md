# 设计系统

用户指定了品牌色/视觉风格时读这份。**没有指定就不要读** —— 运行时自带的令牌已经够用。

---

## 一、令牌体系

所有视觉决策都通过 CSS 自定义属性表达。作者区**只用 `var(--craft-*)`，不写死颜色**。

### 表面与文字

| 令牌 | 用途 |
|---|---|
| `--craft-bg` | 页面底色 |
| `--craft-surface` | 卡片、面板 |
| `--craft-surface-2` | 次级面（代码块、按钮底） |
| `--craft-border` | 分隔线、边框 |
| `--craft-text` | 正文 |
| `--craft-muted` | 次级文字、轴标签、图注 |
| `--craft-faint` | 三级文字、占位符 |
| `--craft-accent` | 链接、焦点环、强调 |

### 图形

| 令牌 | 用途 |
|---|---|
| `--craft-grid` | 网格线 |
| `--craft-axis` | 轴线、刻度线 |
| `--craft-cat-0..7` | 分类色（8 个） |
| `--craft-seq-0..4` | 连续色阶（5 档） |
| `--craft-div-0..4` | 发散色阶（5 档，0 端蓝、4 端红） |

### 排版与间距

| 令牌 | 值 |
|---|---|
| `--craft-font-sans` | 系统字体栈（含中文回退） |
| `--craft-font-mono` | 等宽，用于数值与代码 |
| `--craft-fs-xs/sm/base/lg/xl/2xl` | 12 / 13 / 15 / 18 / 24 / 32 px |
| `--craft-sp-1..8` | 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 px |
| `--craft-r-sm/md/lg` | 4 / 8 / 14 px |
| `--craft-dur-fast/base` | 120 / 240 ms |
| `--craft-ease` | `cubic-bezier(.2,.8,.3,1)` |
| `--craft-measure` | `72ch` —— 阅读型内容的行宽上限 |

## 二、改品牌色

在 `HEAD_SLOT` 里覆盖令牌即可，**明暗两套都要给**：

```html
<style>
  :root, :root[data-theme="dark"] {
    --craft-accent: #7c3aed;
    --craft-cat-0: #a371f7;
    --craft-cat-1: #f778ba;
  }
  :root[data-theme="light"] {
    --craft-accent: #6d28d9;
    --craft-cat-0: #7c3aed;
    --craft-cat-1: #db2777;
  }
</style>
```

`check.mjs` 的 `theme/contrast` 规则会校验：
- `--craft-text` 对 `--craft-bg`、`--craft-muted` 对 `--craft-bg`、`--craft-text` 对 `--craft-surface` ≥ **4.5:1**
- `--craft-accent` 对底色 ≥ **3:1**
- 每个 `--craft-cat-*` 对底色 ≥ **3:1**（低于只告警，不阻断）

注意：它取的是**文档顺序里最后一个** `<style>` 块中的令牌值 —— 两套主题块里若只覆盖了暗色，实际校验的就是暗色那一套，别以为明暗都被验过了。

对比度不达标就调深/调浅，不要为了好看牺牲可读性。

## 三、配色规则

### 分类色

- **最多 8 个**，超过就换编码方式（分组、小倍数），不要再造颜色。
- 相邻系列要在**明度**上有区分，不只是色相 —— 色盲读者靠明度分辨。
- 别用「红/绿」做唯一区分。
- 图例色块自动带 `data-pattern` 图案线索。**注意它只作用在图例上，图形本身没变** ——
  而且图案只有 3 种（`i % 3 + 1`），超过 3 个系列就重复了，别把它当色盲兜底。

### 连续色阶

- 单色相渐变（`--craft-seq-*` 是蓝）比彩虹色阶好 —— 彩虹的明度不均匀，会造出不存在的边界。
- 零有意义的量用发散色阶，中点是中性色。

### 语义色

「红=坏、绿=好」不是普适的（在中国股市恰好相反）。要用就在图注里写清楚。

## 四、排版

- **数值一律用等宽字体** + `font-variant-numeric: tabular-nums` —— 否则拖动滑杆时数字会左右跳。
- 正文行宽 ≤ `--craft-measure`（72ch）。图表不受此限。
- 层级靠字号 + 字重 + 颜色三者配合，不要只靠字号。
- 中文标题不要用斜体（没有真正的斜体字形，会被算法倾斜，很难看）。
- 中英混排时数字和英文两侧留空格，读起来更顺。

---

## 五、动效

- 时长：120ms（状态反馈）／240ms（布局变化）。超过 400ms 会显得迟钝。
- 缓动：`--craft-ease`（快出慢入）。
- **必须**尊重 `prefers-reduced-motion` —— 用 `Craft.animate` 就自动处理了。
- 动效只用来表达**变化**，不用来做装饰。
- 静态状态必须自解释：不看动画也要能理解全部信息。

---

## 六、可访问性底线

| 项 | 要求 |
|---|---|
| 正文对比度 | ≥ 4.5:1 |
| 图形元素对比度 | ≥ 3:1 |
| 焦点可见 | 运行时已提供 `:focus-visible` 外环；自定义控件别用 `outline: none` 干掉它 |
| 键盘可达 | 每个可交互元素都要能 Tab 到 |
| 非颜色线索 | 状态不能只靠颜色 —— 同时用形状、线型、图案或文字 |
| 触屏目标 | 可点击区域 ≥ 44×44px |
| 缩放 | 200% 缩放下不丢内容 |

---

## 七、不要做的事

这些是 AI 生成界面最容易出现的俗套，明确避开：

- 渐变文字、玻璃拟态、霓虹发光
- 无意义的装饰性图标
- 每个卡片都加阴影 + 圆角 + 边框三重叠加
- 大面积高饱和色块
- 用 emoji 当图标（跨平台渲染不一致）
- 深色模式只是把浅色模式反相（要用两套独立调的令牌）
- 12 列等宽卡片网格铺满一屏，每张卡信息量都一样
